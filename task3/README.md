# Задание 3. Технический радар, роадмап и обоснование трансформации «Будущее 2.0»

Состав решения:

1. **`tech_radar.md`** — технический радар: текущие и предлагаемые технологии и методологии по кольцам ADOPT / TRIAL / ASSESS / HOLD. Для каждой технологии указаны поддерживаемые бизнес-сценарии и эффект.
2. **`roadmap.md`** — роадмап изменений технологического ландшафта на 12 месяцев (сентябрь 2026 — август 2027) с привязкой к бизнес-целям: запуск портала самообслуживания, независимое развитие подразделений, качество медицинских и финансовых сервисов. Для каждого этапа — шаги, результаты, ответственные команды и ресурсы.
3. **`justification.md`** — обоснование каждого этапа: влияние на скорость принятия решений, качество сервиса, снижение затрат и масштабируемость.

Решение продолжает Задания 1–2 (целевая архитектура и домены) и обеспечивает:
- промежуточное состояние (через пару месяцев): архитектура согласована, границы доменов определены, проекты запланированы;
- финальное состояние (через год): портал самообслуживания реализован, бизнес-пользователи работают в новой архитектуре, легаси допускается лишь временно в отдельных доменах.
